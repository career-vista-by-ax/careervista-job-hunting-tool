# CareerVista

[English](README.md) · [简体中文](README.zh-CN.md) · [繁体中文](README.zh-TW.md)

让 AI 智能体协助你寻找澳洲工作，本地工作台保存职位证据、推荐理由及申请记录。

## 开始使用

首次使用，告诉智能体：

```text
从 https://github.com/career-vista-by-ax/careervista-job-hunting-tool 安装技能
```

安装后，只需输入：

```text
$careervista-job-search
```

也可以说“使用 careervista-job-search”。智能体会主动说明隐私事项，再逐步引导设置
Docker 或本地应用、明确求职目标，并提供本地职位表链接。无需准备特殊提示词、
预先启动应用或上传简历。已有设置会尽可能复用。

智能体使用你选择的模型、浏览器及文档工具，其费用和数据政策适用；CareerVista
在本地保存记录。`ax-cv` 可协助修改简历，`ax-30-secs` 提供模拟快速审阅。
申请必须由你通过原始招聘广告自行提交，工具不会自动申请或发送消息。
