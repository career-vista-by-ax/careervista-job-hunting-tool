# Source collection

Before any discovery or capture, GET `/api/v1/agent-guide/collection` from the exact running CareerVista origin. It is the authoritative contract for planning, authorization, deferred previews, screening, evidence capture and the Docker headless helper.

Use headless-first access: batch approved keyword/location queries with host search tools/public APIs, then read selected original pages with headless HTTP or Docker Playwright. Use the user's default host browser for an observed login, verification or access barrier, stating the reason. Stop headless requests to a blocked source and keep other approved sources moving. Verify actual query/location and readable original content before accepting evidence. Search snippets, suspicious responses and failure pages cannot establish job/company facts or zero results.

If an older app's collection guide prescribes immediate browser navigation, retain this access order while following that app's supported JSON contract. The Docker helper and optional captureMethod field require an updated image; omit unsupported fields for an older app and report unavailable capabilities honestly. Reuse saved checkpoints and compact previews before reading full evidence into model context.
